# OSCG - Open Source Collaborative Gateway

Your Gateway to Meaningful Open Source collaboration. OSCG is a modern web platform designed to connect developers with impactful open-source projects and foster a thriving community of contributors.

## ✨ Features

- **Project Discovery**: Find meaningful open-source projects that match your interests and skills
- **Community-Driven**: Connect with thousands of active contributors worldwide
- **Real-Time Collaboration**: Work together with developers across the globe
- **Beginner-Friendly**: Perfect for making your first (or next) great contribution
- **Modern UI**: Clean, responsive design built with React and Tailwind CSS

## 🚀 Tech Stack

- **Frontend**: React 19 with Vite for lightning-fast development
- **Styling**: Tailwind CSS for modern, responsive design
- **Icons**: React Icons for beautiful iconography
- **Build Tool**: Vite with Rolldown for optimized builds
- **Linting**: ESLint with React-specific rules

## 🛠️ Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd osci-site
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and visit `http://localhost:5173`

## 📜 Available Scripts

- `npm run dev` - Start development server with hot reload
- `npm run build` - Build for production
- `npm run preview` - Preview production build locally
- `npm run lint` - Run ESLint for code quality checks

## 🎨 Design System

The project uses a custom design system with:
- **Typography**: Montserrat for headings, Roboto for body text
- **Color Palette**: Custom semantic color tokens for consistent theming
- **Components**: Reusable React components following modern best practices
- **Responsive**: Mobile-first design approach
